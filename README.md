# homebrew-tap

Homebrew tap for [ai-proxy-service](https://github.com/veildawn/ai-proxy-releases).

```sh
brew install veildawn/tap/ai-proxy-service
```

Everything the app writes lives in `$(brew --prefix)/var/ai-proxy-service`
(`config.yaml`, `.env`, `secrets.env`, `setup-token`, `data/`). Point
`database.dsn` or `DATABASE_URL` at a reachable PostgreSQL (or MySQL 8.0.13+),
then:

```sh
brew services start ai-proxy-service
```

Upgrade with `brew upgrade ai-proxy-service` — the formula is regenerated by
the release workflow on every release, and startup runs migrations. See the
[main README](https://github.com/veildawn/ai-proxy-releases#readme) for setup,
ports, and the one-time setup token.
